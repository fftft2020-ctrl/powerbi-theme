# Power BI Theme Studio

一个从 0 开始搭建的轻量级网页工具，用于直观设计、预览并导出 Power BI 主题 JSON。

## 功能

- 通过图形界面配置主题名称、字体、主色、辅助色、背景色与数据色。
- 实时预览类似 Power BI 仪表板的卡片、折线图、柱状图和表格样式。
- 自动生成可复制、可下载的 Theme JSON。
- 零依赖静态实现，直接打开 `index.html` 即可使用。

## 使用方式

### 直接打开

直接用浏览器打开 `index.html`。

### 本地启动静态服务

```bash
python3 -m http.server 4173
```

然后访问：<http://localhost:4173>

## 文件结构

- `index.html`：页面结构
- `styles.css`：界面样式与预览布局
- `main.js`：主题状态、实时预览与 JSON 导出逻辑

## 预设与自动保存

- 提供商务蓝、深色、简洁白三套预设；选择预设会替换当前设置。手动修改后显示“自定义”。
- 有效设置自动保存到当前浏览器的 localStorage，刷新后恢复。“恢复默认”也会保存。
- 不同浏览器、网址或文件路径之间不保证共享设置。隐私模式、存储禁用或空间不足时会提示，编辑与导出仍可使用。
- 保存内容损坏或版本不匹配时回退到默认主题；主题名称为空时暂停保存及导出，保留上次有效设置。
- 预览使用固定示例数据，主题修改不会改变销售额或增长率。

## Power BI 导出范围

导出包含主题名称、数据颜色、语义颜色、文字颜色与字体、页面和视觉对象背景。
字体使用 Power BI 的 textClasses/fontFace；背景使用 color/solid/color 结构，并设置为不透明。
圆角、阴影和辅助色仅用于网页预览，不写入主题 JSON，也不再导出自定义 custom 字段。
预览是示意效果；Power BI 中已有的手动格式可能覆盖主题，字体需在目标环境中可用。

下载后，在 Power BI Desktop 的“视图 → 主题 → 浏览主题”中选择 JSON。
导出字段已对照 [Microsoft 官方主题格式定义](https://github.com/microsoft/powerbi-desktop-samples/tree/main/Report%20Theme%20JSON%20Schema) 检查；仍需在实际使用的 Power BI Desktop 版本中完成导入验收。
